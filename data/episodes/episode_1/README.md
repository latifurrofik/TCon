# Episode 1 — Kamu Sadar Sedang Disetir?

Workspace produksi untuk episode pertama seri **Disetir Media Sosial**.

- Simpan maksimal satu thumbnail YouTube langsung di root folder sebagai `thumbnail.jpg` atau `thumbnail.png`.
- Keberadaan file bukan berarti sudah disetujui. Registrasikan sebagai `pending_review`, lalu lakukan pemeriksaan visual sebelum approval.
- Perintah dan alur: `docs/THUMBNAIL-MANAGER.md`.
- Jangan masukkan thumbnail ke `public/assets/library/`; thumbnail bersifat spesifik untuk episode.
- Aset reusable lintas episode tetap dapat dikelola melalui asset library.

File legacy `data/episode-01.json` dipertahankan sampai semua referensi pipeline dipindahkan dan diuji.
