# Episode 1 — Kamu Sadar Sedang Disetir?

Workspace produksi untuk episode pertama seri **Disetir Media Sosial**.

- Simpan thumbnail YouTube episode ini langsung di root folder dengan nama `thumbnail.jpg` atau `thumbnail.png`.
- Jangan masukkan thumbnail ke `public/assets/library/`; thumbnail bersifat spesifik untuk episode.
- Aset lain yang memang reusable lintas episode dapat dikelola melalui asset library.

Sumber kerja episode ini berada di folder ini. File legacy `data/episode-01.json` tetap dipertahankan untuk kompatibilitas sampai seluruh referensi pipeline dipindahkan dan diuji.
