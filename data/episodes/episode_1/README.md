# Episode 1 — Kamu Sadar Sedang Disetir?

Workspace produksi untuk episode pertama seri **Disetir Media Sosial**.

- Simpan gambar hook episode ini beserta prompt dan kandidatnya di folder `hook/`.
- Jangan masukkan gambar hook ke `public/assets/library/`; hook bersifat spesifik untuk episode.
- Aset lain yang memang reusable lintas episode dapat dikelola melalui asset library.

Sumber kerja episode ini berada di folder ini. File legacy `data/episode-01.json` tetap dipertahankan untuk kompatibilitas sampai seluruh pipeline Remotion dipindahkan dan diuji.
