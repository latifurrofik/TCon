# Episode 6 — Konten Marah Sengaja Dibuat

Series: **Disetir Media Sosial**

Folder kerja episode ini mengikuti struktur standar episode_1.

## Struktur
- `metadata.json`: informasi episode
- `naskah/`: naskah narasi dan storyboard
- `prompt/`: prompt visual dan produksi
- `assets/`: aset gambar, ilustrasi, dan video
- `audio/`: voice-over dan musik
- `output/`: hasil render final
- `thumbnail.png`: thumbnail episode (ditambahkan setelah disetujui)
