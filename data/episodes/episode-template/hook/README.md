# Hook Visual — Episode N

Folder ini khusus menyimpan gambar utama untuk bagian hook episode ini. Gambar hook **bukan** aset perpustakaan umum dan tidak boleh dimasukkan ke `public/assets/library/`.

## Isi folder

- `hook-image.png` atau `hook-image.webp`: gambar hook final yang dipilih.
- `hook-prompt.md`: prompt dan arahan visual untuk membuat gambar hook.
- `candidates/`: alternatif hasil generasi yang masih dalam proses seleksi (opsional).

## Aturan produksi

- Buat visual hook yang kuat, terbaca di layar ponsel, dan langsung menyampaikan konflik/pertanyaan utama dalam 1–3 detik pertama.
- Utamakan satu gagasan visual dominan; jangan membuat komposisi penuh ornamen.
- Ikuti Visual Production Bible: ilustrasi editorial 2D, palet dan karakter visual seri.
- Simpan kandidat dan versi final hanya di folder episode ini. Jangan mendaftarkan gambar hook ke asset library global.
- Jangan menimpa gambar final tanpa review. Beri nama versi kandidat secara jelas.
- Gambar hook harus direview manusia sebelum dipakai dalam render final.
- Jika gambar hook memakai elemen reusable dari library, referensikan aset sumbernya; jangan salin gambar hook ke library.

Status persetujuan gambar hook dikelola bersama review aset episode. Keberadaan file tidak berarti sudah disetujui.
