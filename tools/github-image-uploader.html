TCon · Image Uploader

Unggah gambar langsung ke repository latifurrofik/TCon dari Android atau browser. Token hanya dipakai di sesi halaman ini dan tidak disimpan.

Buat token dengan akses hanya ke repository TCon dan permission Contents: Read and write.
Siap. Pilih gambar dan masukkan token.

Keamanan: jangan bagikan token kepada siapa pun. Setelah selesai, hapus token dari kolom dan cabut token jika sudah tidak diperlukan. File dengan nama sama akan ditolak agar tidak menimpa file lama.
